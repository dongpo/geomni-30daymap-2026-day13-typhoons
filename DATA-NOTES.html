實際核對
原檔 249,317 列，年份 1884–2026。限定候選 1980–2025，共 106,951 列；MAIN 為 104,388 列。
只保留 IFLAG 第二字元（Tokyo）為 O/V 的原始機構紀錄，使用 TOKYO_LAT/TOKYO_LON/TOKYO_WIND，而非混合 WMO 風速。
此次實際可用 1980–2024 年：1,142 個氣旋、42,118 點。2025 無符合本篩選的紀錄，未做成「零颱風」年份；2026 不納入。此圖不是最新預報或即時監測。
經檢查 SID+UTC 時間無重複，每條路徑按 UTC 遞增，座標合法；相鄰點超過12小時共 0 組。
風速缺值 15,527 點，保留位置，灰色表示未知；不填零，不以其他機構補值。
WP 檔指曾出現在該海盆的氣旋；完整紀錄可能延伸至海盆之外。選單不是該期間所有熱帶擾動的完整清單，因機構覆蓋與原始紀錄篩選有所限制。

強度怎麼讀
TOKYO_WIND：JMA 10分鐘平均最大持續風速，單位 knots（kt，1kt=1.852km/h）。未混用 USA 1分鐘風速，也不換成臺灣輕／中／強颱分類。
下拉選單按「本圖保留紀錄的最高風速」篩選整個氣旋。圖面顏色代表各紀錄的風速；線段採其起點風速色，並非該段處處量測相同。
顏色分組 <64、64–84、85–99、≥100 kt 是視覺比較用區間，不冒稱官方完整分級。

路徑、紀錄與動畫
這是機構事後 best-track 分析，不是原始感測器軌跡。圓點表示供應機構原始紀錄（已排除 IBTrACS 補出的 P 時間點）。
線段連接相鄰紀錄；超過12小時或跨越不連續經度的線段不畫。經度轉為0–360度，讓跨180度向東的路徑連續，不繞行全球。
所有氣旋共用同一條 UTC 全年時間軸，1月1日00:00至12月31日23:59。年份以紀錄與曆年重疊判定，跨年氣旋不僅依 SEASON 欄位分組；仍只涵蓋本資料保留的紀錄。
此刻存在：首筆紀錄時間 <= 播放時間 <= 末筆紀錄時間。首末紀錄代表資料涵蓋邊界，不等同精確物理生成或消散；轉化為溫帶氣旋後如仍有機構紀錄，也可能繼續顯示。
亮頭表示同期氣旋位置，名稱可見；彩色線僅顯示過去72小時，且不畫播放時間之後的紀錄。當末筆紀錄結束，中心與風圈移除；原生 Trip 過去72小時尾跡仍逐漸淡去，殘留尾跡不代表仍在活動。活動數量只計首末紀錄期間內的氣旋。
中心位置和 Trip 尾跡在紀錄之間作經緯度線性內插，非逐分鐘觀測、預測、大圓路徑或精確移動速度。風速不內插，色彩採最近一筆機構紀錄。選取氣旋的側欄清楚標示目前是否剛好原始紀錄時刻，並顯示最近原始UTC時間。
時間播放可選6／24／48／168資料小時每秒，requestAnimationFrame 更新 Kepler.gl 原生 Trip 的時鐘；風圈與中心約每100毫秒更新（實際更新率取決於裝置），並非重新建立所有 Trip 路徑。高速播放可能跨過短時間細節，請降低速度或用上一／下一時刻核對。這是動畫設定，不是效能FPS測量。
點選氣旋只切換詳情並暫停，不重設全年日期。另有明確的「跳至此氣旋首筆紀錄」按鈕、指定UTC日期、從年初播放、上一／下一原始紀錄時刻（全網合併排序）。篩選後沒有同期紀錄會顯示0與說明，不當作網路錯誤。
強度篩選仍依事後完整生命史峰值，並非該時刻已達門檻；例如一個尚弱的氣旋，若後來達100kt，也會通過100kt峰值篩選。讀者不應將此視為當時可知的預報。
預設2024-11-10 00:00 UTC，保留資料中同時有YINXING、TORAJI、MAN-YI、USAGI；此處「4個氣旋」不表示四者當時都已達颱風強度。
路徑／點大小純視覺符號，不代表颱風尺寸、暴風圈、不確定性範圍或災害影響。


30／50 kt 風圈：資料與幾何
取原始CSV的 TOKYO_R30/R50_DIR、LONG、SHORT，僅接受Tokyo IFLAG=O；方向1–8為NE,E,SE,S,SW,W,NW,N，9為對稱圓。
半徑單位海里，乘1.852轉公里。要求最長>=最短>0且方向有效；方向9另要求兩半徑相等。不完整／不一致資料不畫圈。
42,118個紀錄中：30kt完整26,586、缺漏／無效15,532；50kt完整14,885、缺漏／無效27,233。「未提供」可能涵蓋未達門檻或缺報，不當成零面積。
偏心圓概化：圓半徑=(最長+最短)/2；圓心由氣旋中心向最長半徑方向位移(最長−最短)/2。以球面正算產生72段圓環，地球半徑6371.0088km。這是由摘要半徑製作的概化圖形，不是官方精細邊界或完整風場。
動畫內插：只在相鄰兩筆同門檻的半徑/方向都完整時，內插半徑與圓心偏移的東／北向分量；避免359°→0°方向錯誤旋轉。中心位置也作時間內插。任一端缺值則區間不畫該風圈，側欄明示。
精確紀錄時刻使用該筆半徑，即使下一筆缺值也能逐筆查看。不把缺值補成圓，也不以最大風速估算半徑。青色30kt與橙色50kt獨立呈現，不強制修正為嵌套形狀。
沒有雲圖或格網風場，因此不畫虛構旋轉雲帶／風向粒子；中心最大風速不能推導圈內每一位置的風速。符號圈非不確定性範圍，也非災害範圍。
驗證：scripts/geometry-test.cjs 直接測試前端同一幾何函式，41,471個有效風圈、42,765個缺值判定、40,976對時間中點；結果見evidence/wind-geometry-validation.json。原生層實體與操作證據見browser-QA.json/native-trip-runtime.json。

技術與重現
Kepler.gl 3.3.0-alpha.18 原生 type=trip 圖層；每個相鄰紀錄段使用 [lon,lat,0,timestamp_ms]，lineColor 採起點風速。2024年全部門檻共888個段，已由瀏覽器實體圖層 type=trip 驗證。底層 Trip shader 處理時間裁切與漸淡尾跡；沒有以其他製圖工具代作。外部共用時鐘透過 setLayerAnimationTime 驅動，風圈/中心則以 updateDataset 更新獨立 GeoJSON 資料表，不每幀重載整年路徑。
依序執行 scripts/prepare.py、scripts/prepare_wind.py 產生 data/tracks.json、data/land.json 及 evidence/data-audit.json；scripts/build_html.py 產生 index.html。
Python 依賴版本見 requirements-lock.txt；前端 CDN URL 已固定在 index.html/source/bootstrap-template.html。需要網路載入前端套件，不能宣稱完全離線可用。
以 HTTP 靜態伺服器供應此資料夾；直接 file:// 可能因瀏覽器 fetch 限制失敗。
